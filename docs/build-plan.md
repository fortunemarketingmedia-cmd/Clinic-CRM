# Build Plan

## Phase 1: Project Setup

- Next.js frontend
- Express backend
- Prisma
- PostgreSQL
- Environment variables
- ESLint and Prettier

## Phase 2: Authentication

- Login and logout
- JWT access token
- Refresh token
- bcrypt password hashing
- Role middleware
- Admin and receptionist roles

## Phase 3: Branch Module

- Seed branches
- Receptionist branch toggle
- Admin branch filter

## Phase 4: Users

- Admin creates receptionist users.
- User fields: name, email, password, role, status.

## Phase 5: Dashboard

- Admin metrics: leads, patients, revenue, appointments, pending follow-ups.
- Receptionist metrics: today's appointments, today's leads, quick actions, calendar, branch toggle.

## Phase 6: Leads

- Create, edit, delete, view, search, and filter leads.
- Lead statuses: new, booked, confirmed, cancelled, postponed, not arrived, converted.
